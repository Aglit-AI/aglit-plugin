---
name: aglit-avatar-emotions
description: List and use available avatar emotions and animations when avatar mode is enabled.
---

When avatar mode is enabled, list available emotions/animations using `p1_avatar` `get` and read `state.actions`. Use `play_action` with an appropriate existing name while responding. Keep reactions subtle and bounded; do not invent missing expressions or treat a bounce as a facial smile. If no suitable emotion exists, continue normally. Discover the installed tool schema first; this skill does not install emotion assets or runtime bindings.
